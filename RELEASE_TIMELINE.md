# Canary release chronology

This timeline separates development dates from externally verifiable release events.

| Period | Event | Evidence / caveat |
|---|---|---|
| September 2026 | Development commits associated with the 0.2.0 work | Git commit dates; dates do not establish that GitHub received the commits in September |
| October 10, 2026 | Benchmark run on then-current cloned public repositories | `bench/results/`; source snapshot dates are October 10 |
| October 11, 2026 | First GitHub Actions CI runs | See GitHub Actions run history |
| October 2026 | 0.2.0 PyPI release | Exact date/time comes from PyPI release history; publishing event cannot be backdated |

A later benchmark can validate code developed earlier. GitHub commit dates and the date of the first push or CI run record different events.

These notes do not imply benchmark results, PyPI releases, or CI validation before their actual execution.
